# Synthicc for Claude Code

```
/plugin marketplace add dev-synthicc/synthicc-agent
/plugin install synthicc@synthicc-agent
```

The plugin adds the Synthicc skill and the MCP server at https://preview.synthicc.net/mcp. On first use, sign in with Synthicc in the browser. Docs: https://preview.synthicc.net/docs/agents

This repository is generated from the Synthicc app; don't edit it by hand.
